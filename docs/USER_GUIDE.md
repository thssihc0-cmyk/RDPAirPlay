# RDP AirPlay 用户使用说明

版本：0.1.0  
适用：iPhone / iPad，iOS 16 及以上

本文面向最终用户，介绍如何连接 Windows 远程桌面、日常操作，以及 AirPlay 电视扩展模式。

---

## 1. 准备工作

### 1.1 被控端（Windows 电脑）

1. 打开 **设置 → 系统 → 远程桌面**，启用远程桌面。
2. 确认用于登录的 Windows 账户有远程访问权限。
3. 若从外网连接，需在路由器上转发 **TCP 3389**（或你自定义的 RDP 端口）。
4. 记下电脑的 **局域网 IP** 或 **公网 IP / 域名**。

### 1.2 控制端（iPhone / iPad）

1. 从 TestFlight / 开发安装等方式安装 **RDP AirPlay**（主屏幕显示此名称）。
2. 首次连接时允许 **本地网络** 访问；若需远程通话，允许 **麦克风** 权限。
3. 建议通话、AirPlay 扩展时 **保持 App 在前台**，避免锁屏导致麦克风中断。

---

## 2. 添加主机并连接

1. 打开 App，点右上角 **＋** 添加主机。
2. 填写：
   - **显示名**：便于识别的名称（如「家里电脑」）
   - **地址**：IP 或域名
   - **端口**：默认 `3389`
   - **用户名 / 密码**：Windows 登录凭据（密码保存在系统 Keychain，不会明文存储）
   - **分辨率**：可选预设或自定义宽高
3. 保存后，在主机列表中点击该主机即可连接。
4. 顶部绿点 **已连接** 表示会话成功；失败时会弹出可读错误提示。

---

## 3. 手机直连模式（无电视）

连接成功后，手机全屏显示远程 Windows 桌面。

### 3.1 顶部连接栏

| 按钮 | 作用 |
|------|------|
| **鼠标指针** | 切换鼠标模式（见下文） |
| **键盘** | 打开 / 关闭软键盘 |
| **AirPlay** | 第二屏设置与检测 |

### 3.2 底部工具栏

| 按钮 | 作用 |
|------|------|
| **键盘** | 同顶部，切换软键盘 |
| **鼠标指针** | 同顶部，切换鼠标模式 |
| **AirPlay / 扩展 / 镜像** | 外接屏状态与菜单 |
| **自动 / 横屏 / 竖屏** | 切换屏幕方向 |
| **全彩 / 灰度 / 黑白** | 切换或锁定色彩模式 |
| **设置** | 分辨率、音频、第二屏等 |
| **断开** | 结束远程会话 |

### 3.3 两种鼠标模式

**鼠标指针**（默认，推荐熟悉 Windows 的用户）

- 屏幕上显示光标，操作围绕光标进行。
- **单指点击**：在光标位置左键单击。
- **单指长按后拖动**（未放大时）：移动光标。
- **双指捏合**：缩放画面（1×～4×）；缩放以 **光标位置** 为中心，光标在屏幕上的位置保持不变。
- **放大后单指拖动**：平移画面（查看桌面其他区域）；缩回 1× 后恢复为移动光标。
- **双指上下滑动**：滚动滚轮。
- **长按 / 双指轻点**：右键。

**直接触控**

- 手指点哪里，就点到远程桌面哪里（类似触屏 Windows）。
- 双指捏合以 **捏合中心** 缩放；放大后可拖动画布。

在顶部或底部工具栏点 **鼠标指针** 可在两种模式间切换。

### 3.4 软键盘

点 **键盘** 打开后，底部出现 Microsoft Remote Desktop 风格键盘：

1. **辅助键区**（上方）：F1–F12、Tab、Ins、Home、PgUp、Del 等；可切换 **Fn / 123 小键盘 / 方向键** 三页。
2. **修饰键行**：Ctrl、Alt、Shift、Win（点一下锁定，再点取消）。
3. **QWERTY 字母区**：英文输入；**Shift** 切换大小写。
4. 点 **123** 或 **中文**：切换到 iOS 系统键盘，可输入中文或符号。

关闭键盘后，底部显示 **Ctrl / Alt / Shift / Win** 及 Esc、Tab、Backspace、Enter、Ctrl+Alt+Del 等快捷键。

### 3.5 弱网与色彩

网络较差时，可在底部选 **灰度** 或 **黑白**，减少流量、提高可操作性。  
**全彩** 菜单中可 **锁定** 当前模式，避免自动切换来回跳。

## 4. 电视扩展模式（AirPlay）

适合「电视上看桌面、手机当遥控器/触控板」的场景。

### 4.1 连接步骤

1. **先进入远程会话**，并保持 RDP AirPlay **在前台**（不要切到主屏幕）。
2. 从 iPhone **控制中心 → 屏幕镜像**（或 AirPlay），选择你的 Apple TV / 电视。
3. 返回 App，观察顶部状态：
   - **接管中**：系统已连上 AirPlay，App 正在申请独立扩展屏。
   - **电视扩展**：成功；电视应显示远程 Windows 桌面，手机变为触控板界面。
4. 若长时间停在 **接管中**：
   - 断开 AirPlay，重新连接；
   - 确认 App 仍在前台；
   - 在 AirPlay 菜单中点 **刷新检测** 或 **启用扩展模式**。

### 4.2 手机界面（扩展模式）

自上而下：

```
┌─────────────────────────┐
│  连接栏（状态 / 键盘等）  │
├─────────────────────────┤
│                         │
│      触控板（尽量大）     │  ← 单指滑动移动指针
│                         │
├─────────────────────────┤
│  左键  │  右键            │
├─────────────────────────┤
│  功能键 / 完整键盘       │  ← 点「键盘」展开
└─────────────────────────┘
│  底部工具栏              │
```

**触控板手势**

| 操作 | 效果 |
|------|------|
| 单指滑动 | 移动远程鼠标指针 |
| 单指点击 | 左键（在光标处） |
| 长按 | 右键 |
| 双指滑动 | 滚动 |
| 双指轻点 | 右键 |

**左键 / 右键** 按钮：按住即按下，松开即抬起，适合拖拽、框选。

点 **键盘** 后，底部展开与手机直连相同的 **完整软键盘**（F 键 + 修饰键 + QWERTY）；再次关闭键盘可恢复功能键区，触控板仍占据中间最大空间。

### 4.3 扩展 vs 镜像

| 模式 | 说明 |
|------|------|
| **扩展**（推荐） | 电视只显示远程桌面；手机是触控板 + 键盘。 |
| **镜像** | 电视与手机显示相同内容（系统级镜像，非独立第二桌面）。 |

可在 **AirPlay 菜单** 或 **会话设置 → 第二屏** 中切换。断开 AirPlay 后，画面自动回到手机，**远程连接不会断开**。

## 5. 会话设置

点底部 **设置**（滑块图标）可调整：

- **色彩模式**与是否锁定  
- **分辨率**（宽高数字，点「应用分辨率」）  
- **音频**：听筒 / 免提切换  
- **第二屏**：扩展 / 镜像、刷新检测  

---

## 6. 蓝牙键鼠（可选）

- 配对 **蓝牙鼠标或触控板** 后，可在远程画布或触控板上直接使用（移动、点击、滚轮）。
- 配对 **蓝牙键盘** 后，在 **软键盘关闭** 时，按键会发送到远程 Windows。

---

## 7. 远程微信接听（说明）

RDP AirPlay **不会**把微信变成 iPhone 系统电话。流程是：

1. 远程 Windows 上微信来电，你应能在 iPhone 上 **听到铃声**（远程音频播放）。
2. 在远程桌面画面上 **点击「接听」**。
3. 对方听到的是 **Windows 会话里的麦克风**（来自 iPhone 麦克风重定向）。

**请注意**

- 通话时请 **保持 App 前台**，锁屏可能导致麦克风停止。
- 若对方听不到你，在 Windows **声音设置 → 输入设备** 中检查是否选中了 RDP 重定向的麦克风；部分电脑需手动切换默认录音设备。
- 弱网 + 远程桌面会有延迟，以「能听清、能对话」为目标，不保证与原生电话相同体验。

## 8. 常见问题

**Q：连接失败，提示认证错误或主机不可达？**  
检查 IP、端口、用户名密码；确认 Windows 已开远程桌面且防火墙放行 3389。

**Q：画面有但无法点击？**  
确认未处于 Stub 测试模式（开发版无 FreeRDP 库时仅显示占位画面）；尝试切换 **鼠标指针 / 直接触控**。

**Q：AirPlay 后电视仍是手机镜像，不是远程桌面？**  
先进入会话再开 AirPlay；保持 App 前台；断开重连；在 App 内选择 **扩展模式** 并点 **刷新检测**。

**Q：放大后拖不动画面？**  
需先 **双指捏合放大** 到 1× 以上，再用单指拖动；1× 时单指拖动是移动光标。

**Q：中文怎么输入？**  
打开软键盘后，点 QWERTY 下方的 **中文**，使用 iOS 系统输入法，文字会发送到远程。

**Q：如何断开？**  
点底部 **断开**（电话挂断图标），或返回并确认结束会话。
