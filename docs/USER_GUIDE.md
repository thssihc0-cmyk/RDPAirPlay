# RDP AirPlay 用户使用说明

版本：0.1.0  
适用：iPhone / iPad，iOS 16 及以上

本文面向最终用户。**RDP AirPlay 需要连接 AirPlay 电视** 才能进行触控与键盘操作；未连接电视时会显示引导页。

---

## 1. 准备工作

### 1.1 被控端（Windows 电脑）

1. 打开 **设置 → 系统 → 远程桌面**，启用远程桌面。
2. 确认用于登录的 Windows 账户有远程访问权限。
3. 若从外网连接，需在路由器上转发 **TCP 3389**（或自定义 RDP 端口）。
4. **麦克风重定向（远程微信通话必需）**：
   - 专业版/企业版：`gpedit.msc` → **计算机配置 → 管理模板 → Windows 组件 → 远程桌面服务 → 远程桌面会话主机 → 设备和资源重定向** → 启用 **允许音频录制重定向**。
   - Windows Server RDS：在 **会话集合 → 属性 → 客户端设置** 中允许 **音频录制**。
   - 连接成功后，在 **设置 → 系统 → 声音 → 输入** 中应能看到 **Remote Audio** / **远程音频** 设备。

### 1.2 控制端（iPhone / iPad + 电视）

1. 安装 **RDP AirPlay**（主屏幕显示此名称）。
2. 准备 **Apple TV 或支持 AirPlay 的电视**。
3. 首次连接时允许 **本地网络**；使用远程通话时允许 **麦克风** 权限。
4. 会话期间 App 会 **保持屏幕常亮**；仍建议保持 App 在前台，避免 iOS 限制后台麦克风。

---

## 2. 添加主机并连接

1. 打开 App，点 **＋** 添加主机。
2. 填写显示名、地址、端口（默认 3389）、用户名/密码。
3. 建议开启 **扬声器** 与 **麦克风（远程录音）**。
4. 保存后点击主机连接。
5. 若启用麦克风，首次会弹出 iOS **允许访问麦克风**，请选择允许。

---

## 3. 连接电视（必需）

1. **先进入远程会话**，保持 App 在前台。
2. **控制中心 → 屏幕镜像 / AirPlay** → 选择电视。
3. 返回 App：
   - 若成功：界面变为 **大触控板 + 底部操作区**，电视显示 Windows 桌面。
   - 若仍为引导页：点 **刷新检测** 或断开 AirPlay 后重连。
4. 引导页期间 RDP 可能已在后台连接；电视就绪后自动进入触控板模式。

---

## 4. 电视扩展模式操作

### 4.1 界面布局

```
┌─────────────────────────┐
│  连接栏（状态 / 键盘等）  │
├─────────────────────────┤
│      触控板（尽量大）     │
├─────────────────────────┤
│  左键  │  右键            │
├─────────────────────────┤
│  功能键 / 完整软键盘       │
├─────────────────────────┤
│  底部工具栏              │
└─────────────────────────┘
```

### 4.2 触控板手势

| 操作 | 效果 |
|------|------|
| 单指滑动 | 移动远程鼠标指针 |
| 单指点击 | 左键（在光标处） |
| 长按 | 右键 |
| 双指滑动 | 滚动 |

**左键 / 右键** 按钮：按住即按下，松开即抬起。

### 4.3 软键盘

点 **键盘** 打开 Microsoft Remote Desktop 风格键盘：

1. **辅助键区**：F1–F12、Tab、Ins、Home 等；可切换 Fn / 123 小键盘 / 方向键。
2. **修饰键**：Ctrl、Alt、Shift、Win（点一下锁定）。
3. **QWERTY 字母区**：英文输入。
4. 点 **123** 或 **中文**：切换 iOS **系统键盘**，可输入中文（经 RDP Unicode 发送到 Windows）。

关闭键盘后，底部显示 Esc、Tab、Backspace、Enter、Ctrl+Alt+Del 等快捷键。

### 4.4 底部工具栏

| 按钮 | 作用 |
|------|------|
| 键盘 | 打开/关闭软键盘 |
| AirPlay | 第二屏状态与菜单 |
| 自动/横屏/竖屏 | 屏幕方向 |
| 全彩/灰度/黑白 | 色彩模式 |
| 设置 | 分辨率、音频、第二屏 |
| 断开 | 结束会话 |

## 5. 会话设置

- **色彩模式**与锁定  
- **分辨率**（应用后可能需要重连生效）  
- **音频**：听筒 / 免提  
- **第二屏**：扩展 / 镜像、刷新检测  

---

## 6. 远程微信接听

1. 远程 Windows 上微信来电，iPhone 应能听到铃声（远程音频播放）。
2. 在电视画面所对应的远程桌面上 **点击「接听」**（用手机触控板移动指针并点击）。
3. 对方应听到 **Windows 会话中的麦克风**（来自 iPhone 经 RDP 重定向）。

**若对方听不到你：**

1. 确认 iPhone **设置 → RDP AirPlay → 麦克风** 为「允许」。
2. 确认 App 主机配置中 **麦克风（远程录音）** 已开启。
3. 在 Windows **设置 → 系统 → 声音 → 输入** 中选择 **Remote Audio** 为默认设备。
4. 检查 Windows 组策略 / RDS 是否允许 **音频录制重定向**（见 §1.1）。

---

## 7. 蓝牙键鼠（可选）

- 蓝牙鼠标/触控板：可在触控板上使用。
- 蓝牙键盘：在 **软键盘关闭** 时，按键发送到远程 Windows。

## 8. 常见问题

**Q：没有电视能用吗？**  
当前版本 **必须连接 AirPlay 电视** 才能操作。无电视时仅显示引导页；可连接 RDP 但无法在手机上直接看桌面或触控。

**Q：AirPlay 后仍是引导页？**  
保持 App 前台；断开 AirPlay 重连；点 **刷新检测**；确认电视支持 AirPlay 扩展（非仅镜像）。

**Q：中文输入闪退？**  
请更新到最新版本；使用系统键盘（点「中文」）前确保已连接电视并打开 App 内键盘。

**Q：能听到对方，对方听不到我？**  
见 §6 与 §1.1；重点检查 Windows 输入设备与 **允许音频录制重定向** 策略。

**Q：会话中手机会自动锁屏吗？**  
不会。连接期间 App 会禁止 idle 锁屏；断开或离开会话后恢复系统默认。

**Q：如何断开？**  
点 **断开**，或从引导页点右上角断开。
